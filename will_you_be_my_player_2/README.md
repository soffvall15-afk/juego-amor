# Will You Be My Player 2?

Proyecto web autónomo de aventura romántica retro. Abre `index.html` directamente en el navegador; no necesita instalación ni servidor.

Para personalizar nombres, recuerdos y carta, edita `config.js`. El juego incluye cinco pantallas/niveles, objetos interactivos, diálogos, progreso y final con respuesta afirmativa o respetuosa.
